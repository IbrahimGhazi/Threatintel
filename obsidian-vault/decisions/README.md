# Decisions (ADRs) #decision

One file per decision. Filename `YYYY-MM-DD-short-slug.md`. Template:

```markdown
# YYYY-MM-DD — Title

**Status:** proposed | accepted | superseded by [[...]]
**Context:** What's the situation forcing the decision?
**Options considered:**
1. ...
2. ...
**Decision:** What we picked, in one sentence.
**Consequences:** What follows — positive and negative.
**Revisit when:** signal that would make us re-open this.
```
